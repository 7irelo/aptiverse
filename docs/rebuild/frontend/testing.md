## Purpose

A test pyramid for the web app: fast unit tests (Vitest with MSW), Playwright E2E with mobile projects first and axe in both colour schemes, visual snapshots, and security assertions, all runnable locally and in CI.

## Scope

- Vitest: `vitest.config.mts` (jsdom, `tests/setup.ts`, `server-only` stub, `src/**/*.test.{ts,tsx}`), MSW handlers in `tests/msw/`.
- Playwright: `playwright.config.ts` (projects `mobile-chrome` Pixel 7, `mobile-safari` iPhone 14, `desktop-chrome`; app servers on 3100 with `e2e/mock-api.mjs` and 3101 with the API down), specs in `e2e/`.
- New: `e2e/support/axe.ts`, `e2e/support/auth.setup.ts`, `e2e/security.spec.ts`, `tests/factories/`.
- CI wiring lives in `ci/web-pipeline.md`.
